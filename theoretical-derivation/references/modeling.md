## 1. R0 问题数学化（N0 必审 · 强推理档 · 挂 P1）

**目的**：把开放的推导任务收敛为可执行的数学问题，为 R1/R2 提供**共同起点**。R0 错了，下游全部白做。

**输入**：`<root>/inputs/` 下的问题背景、已有材料、约定文件 + 用户任务描述。

**产出**：`[R0]<任务>_问题陈述_vN.md`，强制章节：

1. **§1 定位**：问题来源、结论服务的下游（谁用、用来做什么）、已有结果（若有，作为反向验证基线，R1 阶段禁引）。
2. **§2 约定锁定**：符号、单位制、参考系/坐标系、参数化方式、正负号约定（如旋转扰动取左乘还是右乘、角度正方向、应力拉正压负）。有项目约定文件则引用，没有则在此当场锁定。**后续阶段不得改选**。
3. **§3 数学归约**：
   - 3.1 问题陈述：「如何〔求/估计/设计〕…，以实现/支撑…」
   - 3.2 问题类别：正向建模（给定输入求响应）/ 反问题（参数辨识、状态估计）/ 优化设计 / 轨迹规划 / 控制律设计 / 证明类，说明归类依据
   - 3.3 输入　3.4 输出　3.5 假设（逐条编号 A1、A2…）　3.6 约束
4. **§4 验证判据**：按 `verification.md` 为本任务选定外部锚点类型（3a/3b/3c）、标准工具库、容差带；锚点不可得须说明原因。
5. **§5 与已有材料的关系**：沿用/修正/新建。
6. **§6 分解计划**：子结构清单（按自然数学边界切）+ 各子结构的独立锚点 + 接口契约（共享量、约定、量纲链）。子结构数决定 harness 档位（`verification.md` §4）。

**N0 审阅四要点**：归约定位对不对、输入/输出/假设/约束全不全、判据覆盖够不够、结构假设是否全部由人钉死。同时确定**工作模式**（SKILL.md §3）与 **harness 档位**。未过不进 R1。

## 2. P1 结构假设钉死（R0 执行，R2 复查）

【拦截的失误】题面只说"若干平行连接杆"时，模型会自动补上"对称布置"；拓扑、对象性质类信息缺失时，模型倾向补成最规则、最易解的情形。

凡涉及真实结构/系统的建模，R0 必须先锁定以下要素，**缺项由用户显式给定，禁止 Claude 自行补成"规则情形"**：

- [ ] **拓扑**：串联 / 并联 / 混联？闭环与旁路如何连接？
- [ ] **布置与对称性**：对称还是偏置？（决定有无耦合项）
- [ ] **构件性质**：刚体还是弹性体？哪些构件可刚化、哪些须计柔度？
- [ ] **边界与接触**：固支/铰支/自由？有无接触、间隙、摩擦？
- [ ] **对象的数学性质**：大运动还是小变形线性化？状态空间维数与其物理含义（同维数不等于同物理意义，如刚体位姿与弹性微变形）。
- [ ] **载荷与时间尺度**：静态/准静态/动态？确定性还是随机？

自检问句（R0 一次、R2 复查一次）：
- 我有没有替用户补了一个用户没说的结构假设？
- 如果补了，有没有显式标出并说明边界？（最低要求：标出 + 标边界）

## 3. P2 完整通解次序（R1/R2 推导段）

【拦截的失误】第一次积分定出 C₁=0 后，第二次积分式里直接不写 C₁x 项——结论虽对，但破坏了"先通解、再定解"的可复现次序。

含待定常数/待定量时，强制次序：

1. 先写出含全部待定量的**完整通解**（即便"已经知道"某项会等于零）。
2. 再**逐个**代入边界/相容条件求解，每代入一个说明其物理依据。
3. 不得在通解书写阶段提前省略"预判为零"的项。

自检：通解里待定常数的项数 = 定解条件数吗？有没有哪一项是"因为知道它最后等于零"而没写的？

```
反例：EI·y' = P(Lx − x²/2) + C₁，由 y'(0)=0 得 C₁=0；
      EI·y  = P(Lx²/2 − x³/6) + C₂                ← 跳过了 +C₁x
正例：EI·y  = P(Lx²/2 − x³/6) + C₁x + C₂，代入 C₁=0，再由 y(0)=0 得 C₂=0
```

## 4. P3 隐含前提显式化（R1/R2 推导段）

【拦截的失误】写"超静定次数 = 4−2"时不说明为何平衡方程算 2 个而非 3 个，逻辑链留缺口。

凡出现"方程数 = N""未知量 = M""自由度 = K"之类计数，或任何"取某值 / 略去某项"的动作，必须紧跟依据。

强制句式：「……为 N，因为〔依据〕」。常见依据：因忽略轴向 / 因对称性 / 因准静态 / 因小变形线性化 / 因刚体假设 / 因独立同分布。

```
反例："平面梁有效平衡方程 2 个，超静定次数 = 4 − 2 = 2"
正例："平面问题平衡方程本为 3 个，∑Fx=0 因不计轴力自动满足，有效为 2 个；故超静定次数 = 4 − 2 = 2"
```

自检：每一个数字（方程数、自由度、阶次）都交代来源了吗？

## 5. P4 有效域审查三问（R3；得闭式结果后强制）

【拦截的失误】解出 K = nEA/ℓ 后直接转向应用，未审视模型何时失效。开放建模中这是最需要外部规则补强的弱项。

得到闭式结果后、转向"结论/应用"之前，必须答三问并写入交付包 §7.4：

1. **成立前提**：结果依赖哪些假设？逐条列全（材料/几何/边界/载荷/拓扑）。
2. **失效条件**：每个假设被打破时模型如何变化，给出修正方向。
   例：刚化假设破 → 串联接入构件柔度；对称假设破 → 出现耦合项；无接触假设破 → 并联支路加接触刚度。
3. **推广路径**：通往一般情形的建模出口在哪。
   例：偏置布置下标量刚度退化为 6×6 柔度矩阵对应分量之逆，不再是简单代数和。

**硬性约束**：只答了 (1) 没答 (2)(3) → R3 未完成，不得进 R3.5/R4。

## 6. 四问闸门（R4 收尾；任一答"否"则退回）

- [ ] **P1**：没有替用户默认补全未给定的结构假设；若补了，已显式标出并标边界？（否 → 退 R0）
- [ ] **P2**：通解项数 = 定解条件数，无"预判为零"的省略项？（否 → 退 R1/R2）
- [ ] **P3**：每个计数/取值都交代了依据？（否 → 退 R1/R2）
- [ ] **P4**：有效域三问（前提/失效条件/推广路径）都答了？（否 → 退 R3）

> 闸门看的是"链条实不实"，不是"写得多不多"。篇幅不进闸门。
