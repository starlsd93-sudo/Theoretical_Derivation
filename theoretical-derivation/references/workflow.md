# workflow：R1–R5 详规 + 失败回退 + 检查表

> R0 详规见 `modeling.md` §1；判据见 `verification.md`；多端规则见 `cross-validation.md`。下文 `<任务>` 为任务名。

## R1 独立推导（可选审阅 · 强推理档 · 挂 P2/P3）

**目的**：仅基于 `inputs/` 中的问题材料与约定独立推导，**不引任何外部文献**（防先入为主）。

**产出**：`[R1]<任务>_推导A_vN.md`，含：① 推导起点（几何/物理抽象）② 分阶段推导（代数构造 + 物理直观 + 量纲核算）③ 合成与闭式结果 ④ 与已知形式的等价性 ⑤ **四项自查** ⑥ 关键观察 ⑦ 留给 R3 的对照点。

**四项自查**：
- 符号一致性（按 R0 §2 约定）
- 约定早锁定（正负号、参考系与 R0 §2 一致）
- 量纲一致性（两侧单位对齐，混合量纲显式转换）
- 边界退化（≥ 2 个简化情形）+ 极端参量（≥ 2 个）

**环境差异**：A 端关键代数步骤即时用 sympy/numpy 验证，脚本放 `work/<任务>/temp/`；B 端用网页沙箱轻量验证。

## R2 文献借鉴推导（可选审阅 · 执行档组织，推导段强推理档）

**目的**：用教材/文献对照推导，验证并补强 R1。

**两种角色**：
- **辅助检验**（默认）：教材对照表 + R1 补强清单，必要时出 R1 v1.1；
- **完整重做**：核心结论或需强对比时，独立再推一遍（同挂 P2/P3）。

**★ 文献真实性核查**：每条引用可溯源到 `inputs/refs/` 中的原文或可公开检索的出处；禁止编造文献、章节号、卷期页。R2 复查一次 P1。

**产出**：`[R2]<任务>_推导B_vN.md`

## R3 对比选定（N3 必审 · 强推理档 · 挂 P4）

- **正确性是否决项**：任一处违反符号/量纲/边界自查即淘汰。
- 简洁性、可推广性、与既有框架的融入度作软判据。
- 允许互补整合（R1 骨架 + R2 技巧）。
- **P4 有效域三问**必答（`modeling.md` §5）。
- 决策须留痕（表格：选定结果 / 依据 / 关键差异），否则 R5 无从提取关键决策。

**N3**：用户最终判断，尤其 R1/R2 不一致时。

## R3.5 参数冻结（轻量节点，可与 N3 合并）

几何/物理参数错若拖到 R4 才暴露会整轮返工；多端口径不同会伪装成推导分歧。

- 列全 R4 所用数值参数，每项标：取值 / 出处 / 用户核对栏；
- 标出 R1/R2 中的简化假设（对称几何、近似位置等），由用户判断是否按真值重设；
- 多端并行时冻结表跨端统一下发；
- 核对后**冻结**，R4 以冻结值为唯一输入。

## R4 全程数值验证（N4 必审）

按 `verification.md` 执行五类判据 + 误差分层 + 四问闸门，产出脚本与验证报告。多子结构按 R0 选定的 harness 档组织。

**N4 是最关键的决策点**：用户审阅验证报告，不通过按下方回退路径处理。

## R5 推导交付包（简审 · 执行档）

把 R0–R4 封装为 `templates/derivation-package.md` 规定的交付包，输出至 `<root>/output/`。**只封装、不新增推导、不润色成文**。缺任一必需输入 → 回到对应阶段补，不在 R5 强行生成。

## 失败回退路径

| 失败位置 | 回退到 | 理由 |
|:--|:--|:--|
| R4 精度不达标 | R3 重新选定 | 选定非最优 |
| R4 结构性错误（如应正定而非正定）| R1/R2 修订 | 推导有错 |
| R4 外部锚点对照不一致 | R1/R2 修订 | 推导有错 |
| R4 参数口径错误 | R3.5 重新冻结 + R4 重跑 | 参数错非推导错 |
| R5 发现 R4 漏判据 | R4 补算例 | 验证未覆盖 |
| R5 发现 R0–R3 矛盾 | 矛盾源头 | 推理链不一致 |
| 跨端孤立分歧 | 先判口径，再判推导 | 口径差常伪装成推导分歧 |
| 任意节点的概念性质疑 | R0 | 根基可能错 |

**回退规则**：永远回到最早的错误源头，不做局部修补。
