# cross-validation：双路推导与跨端多方验证

> 本文件是执行环境选择、三角范式、采信规则、分歧处置与外部结果回收的**唯一来源**。
> 核心观点：多个**独立**端在关键量上于容差内一致，是任何单端无法自证的可信度——价值在"独立端一致"，与哪端更强无关。

---

## 1. 独立性的三个层级

| 层级 | 做法 | 能抓住 | 抓不住 |
|:--|:--|:--|:--|
| 路径独立 | 同会话 R1（无文献）vs R2（有文献）| 推导技巧错、文献映射错 | 会话上文污染、模型偏差 |
| 上下文独立 | 冷启动新会话 / subagent，禁看主线结论 | 自锚定（"引用自己前面推的"）| 模型级系统性偏差 |
| 模型独立 | 外部 AI（不同厂商模型）独立推导 | 模型级盲区与偏差 | 共同的问题设定错误（靠 N0 人审）|

越往下越独立，成本也越高。标准模式用第一层，严格模式至少叠加第二或第三层。

## 2. 执行环境选择

| 任务性质 | 推荐 | 理由 |
|:--|:--:|:--|
| 新颖代数结构（无成熟教材）| **A** | 推-验一体，最早拦错 |
| 数值密集（大量算例/扫描）| **A** | 直接跑 Python |
| 经典领域、长链概念推理 | **B** | 教材对照稳定 |
| 文献对标、理论解释深化、退化诊断 | **B** | 文献交叉印证最深 |
| 独立第二意见 / 盲区补充 | **C** 或冷启动 A | 物理隔离；同会话 B 不作独立第一意见 |
| 主力额度紧张 / 试探性任务 | **C** | 不占主力资源 |
| 核心结论 | **三角 A + C + B** | 见 §3 |

- **A** 的局限：参数口径类错误可能暴露较晚，靠 R3.5 冻结 + R4 锚点兜底。
- **B** 无本地 Python：R4 产出 `[R4]<任务>_验证指令_vN.md`（算例参数 / 公式清单 / 期望输出 / 验证算例 / 失败回退五段）交 A 跑。
- **C** 是第二意见非终裁：产出回主线由 A 核对。

## 3. 三角范式（严格模式）

1. **A 主推 + 终裁**：完整 R0→R5，最深验证，数值以 A 为准。
2. **C 独立复算 + 盲区补充**：从 R0 起独立推导，禁看主线；与 A 容差内一致即强背书，分歧即风险信号，并指出主线框架的盲区。
3. **B 文献对标**：把 A 的推导对到权威文献，做退化诊断与理论解释。

**前提**：各端共用同一份 R3.5 参数冻结表与 R0 §2 约定；否则口径差会伪装成推导分歧。

## 4. 采信规则

- **多端一致项** → 高可信，直接采信。
- **数值终值** → 取经最强验证的端（判据最全 + 外部锚点机精对照 + 最大采样），通常为 A。
- **孤立端分歧** → 重点排查，按 §5 处置。

## 5. 分歧处置顺序

1. **先排除口径差**：参数取值、约定（正负号、扰动侧、参考系）、简化假设（对称 vs 真值）。统一口径后通常消失。
2. **再判推导错误**：同口径仍分歧 → 有端推错，优先排查孤立端（多数端一致者大概率对，但不免检）。
3. **数值终值**：取经最强验证的端。
4. **回退**：确认推错 → 回到该端最早的错误源头，不做局部修补。

## 6. 外部 AI 结果回收

- 委派提示词由 `prompts.md` §F 实例化；两条硬约束：**外部 AI 只写其自己的工作目录**、**动笔前先问用户模型名与产物前缀**。
- 外部产物由用户检查后手动拷入 `<root>/work/<任务>/C/`，Claude 不代拷。
- 回收后由 A 核对：推导链是否完整、关键数值能否在容差内对照。不强制外部端用固定格式。
- 外部端指出的**盲区**逐条评估：补进主线推导，或记入交付包 §8 待办。
- 交付包 §7.5 记录：采信哪端数值、多端一致项、孤立分歧根因、盲区处置。
