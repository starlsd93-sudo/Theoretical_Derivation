> 本文件是 R4 判据、容差、harness 档位与接缝四查的**唯一来源**。判据领域无关；R0 §4 据此为当前任务选定锚点、工具与容差。

## 1. 五类判据（标准/严格模式缺一不可；轻量模式至少 1/2/3）

1. **解析 vs 数值一致性**：解析导数/雅可比/梯度/积分 与 数值差分/数值积分逐点对照，相对误差达机器精度量级。拦截求导、符号、代数错误。
2. **结构性质核验**：满秩、条件数、对称性、正定性、守恒律、齐次/缩放律、量纲一致性——推导对象按其数学性质应满足的不变量。拦截构造错误。
3. **★ 独立外部锚点对照（强制）**：必须有一个**独立于本推导**的锚点，逐项数值对照。按可得性择优：
   - **3a 经典闭式解**（首选，若文献/教材中存在）；
   - **3b 独立第二推导**：另走一条推导路径，或换坐标系/参数化，结果应等价（适用无现成闭式的开放建模）；
   - **3c 可解析特例退化**：在对称、单支链、零载荷、小角度等特例下，一般式应退化为已知解析结果。

   **为什么强制**：满秩、正定、缩放律这类自洽验证查不出"形式自洽但物理错误"（力臂取错、耦合符号反号）。三者都不可得 → R0 须声明原因，由 N4 审。
4. **★ 标准工具/库实跑（强制，不得只写在注释里）**：用成熟实现独立复算，例如：
   - 数值线代 / 概率统计 → numpy、scipy.linalg、scipy.stats
   - 符号推导 → sympy
   - 优化 / 运动学 → scipy.optimize、机器人学工具箱
   - 几何视觉 / 位姿 → OpenCV、scipy.spatial.transform
   - 结构力学 → 有限元求解器或 sympy 符号解

   至少一端真实跑通；写了调用却在运行时被跳过不算。无对口库 → 用 3b 独立第二实现替代并在报告中注明。
5. **随机采样交叉验证**：含随机性的结论（协方差、误差传播、CRLB 等）用蒙特卡洛，经验/解析比值 ∈ [0.9, 1.1]；确定性结论改用参数空间随机采样 + 边界/极端扫描。**须对外部基线或锚点**，单纯的理论/MC 自洽比值不能替代判据 3。

**容差**（R0 §4 落定具体带）：解析–数值、外部锚点对照 < 1e-6（相对）；矩阵对称性 ‖K−Kᵀ‖ < 1e-6·‖K‖；其它工程量按物理意义设带（如长度 0.01 mm、像素 0.01 px）。

## 2. 误差来源分层

R4 须显式区分：
- **独立观测噪声**：∝ 1/√N 衰减，主导时增样本即可；
- **配置/系统误差**：跨观测相关、弱依赖 N、不被平均消减，主导时须靠标定或设计消减。

做一次 N 扫描或敏感性扫描，说明在工作区间内谁主导、临界点在哪。

## 4. 验证 harness：子结构拆分 → 独立验证 → 接缝 → 系统

把软件工程"单元测试 → 集成测试"的纪律搬到推导上：不等推完整模型才验证，而是按 R0 §6 分解计划，每个子结构**独立 PASS 后才合并**，合并时强制**接缝四查**，最后跑**系统级**五类判据。

| 档位 | 做法 | 推荐条件 |
|:--:|:--|:--|
| **H1 内联模块化**（默认）| 单会话内每子结构一个 `@module` 验证函数，自带锚点 + 容差 | 子结构 ≤ 2，单会话可控 |
| **H2 subagent 扇出** | 每子结构交独立上下文的 subagent 推导 + 验证，回传 verdict，主会话只合并 PASS 模块 | 子结构 ≥ 3 且相互独立；担心单会话自锚定 |
| **H3 流水线编排** | decompose → 并行模块验证 → barrier 接缝 → 合并 → 系统验证 → 对 FAIL 对抗复验 → 循环至全过 | 子结构多、需可审计流水线；须用户显式开启 |

> H2 的 caveat：同一模型的多个 subagent 只是**上下文多样性**，抓不住模型级系统性偏差，不替代跨模型复算（`cross-validation.md`）。

### 4.1 接缝四查（合并步强制）

各模块 PASS 后朴素合并，整体仍可能错——错在接口。

1. **共享参数同一性**：跨模块共享量用同一份 R3.5 冻结值。
2. **约定一致性**：正负号/扰动侧、参考系、参数化跨模块一致。
3. **量纲链**：上游出口单位 = 下游入口单位，转换显式。
4. **★ 合成 = 独立整算**：装配模型在一个算例上的输出，等于一条独立的整模型计算（判据 3b 用在系统级）。这一条抓"每块都对、拼起来错"。

### 4.2 模块 verdict schema

```json
{
  "module": "<子结构名>",
  "status": "PASS | FAIL",
  "anchor_type": "3a_closed_form | 3b_second_derivation | 3c_degenerate_special",
  "criteria": {"analytic_vs_numeric": true, "structural": true, "external_anchor": true,
               "library_xcheck": true, "random_sampling": true},
  "key_values": {"<量名>": "<数值>"},
  "tolerance": "<容差带>",
  "notes": "<非阻断观察 / 锚点不可得说明>"
}
```

H2/H3 的 subagent 强制返回此 schema；H1 由骨架脚本自动写出 `<module>_verdict.json`。

### 4.3 工程实践

- **回归**：改了任一模块或接缝后全量重跑。
- **golden 值**：锚点给出的已知良好数值冻结为回归基线。
- **静态门（可选）**：跑数值前对验证脚本执行 `basedpyright --outputjson <script.py>`，`summary.errorCount == 0` 才放行。它拦截脚本的实现 bug（拼写错、未定义名、某路径未赋值），不拦推导错误。配置见 `templates/pyrightconfig.json`（文件名须为 `pyrightconfig.json`）；未安装则跳过，不阻塞。

## 5. 五道防线（剩余风险为经验估计，仅示意相对强弱）

| 防线 | 阶段 | 主要拦截 | 剩余风险 |
|:--:|:--|:--|:--:|
| 1 | R1 四项自查 + 即时脚本 | 符号笔误、简单代数错 | < 5% |
| 2 | R2 教材对照 + 文献真实性核查 | 概念映射错、幻觉（编造文献/数值）| < 3% |
| 3 | R3 双路比对 | 系统性偏差 | < 2% |
| 4 | R4 外部锚点 + 标准库 | 代数错 + 形式自洽的物理错（最强）| < 0.1% |
| + | 跨端独立复算（严格模式）| 单端/单模型系统性偏差 | 一致项更低 |

另：R3.5 参数冻结专拦参数口径错误。
