## B —— 问题归约（R0）

```
请把以下问题归约为数学问题：
1. 归类（正向建模 / 反问题 / 优化设计 / 轨迹规划 / 控制律设计 / 证明），说明依据。
2. 列出输入、输出、假设（编号 A1…）、约束。
3. 锁定结构要素：拓扑、布置与对称性、构件刚/弹性、边界与接触、大运动还是小变形、载荷与时间尺度。
   我未明确给定的，列出来问我，不要自行补成默认情形。
4. 锁定约定：符号、单位、参考系、参数化、正负号（如旋转扰动左乘还是右乘）。
5. 为本问题选定外部验证锚点（闭式解 / 第二推导 / 特例退化）与容差。

问题：【在此粘贴】
```

## C —— 推导（封闭推导用 1–4；开放建模追加 5，并调高思考预算）

```
请对以下任务做推导，严格遵守：
1. 列出全部建模假设（材料/几何/边界/载荷/拓扑）。
2. 从基本控制方程出发；含待定常数时先写完整通解，再逐个代入定解条件，
   每代入一个说明物理依据，不得因预判某常数为零而提前省略对应项。
3. 凡出现方程数、自由度、阶次等计数，或略去某项的动作，紧跟一句依据（"因……"）。
4. 公式展开到物理量层，用 LaTeX；最后做量纲检查与至少两个特例退化检查。
5. 得到闭式结果后、谈应用之前，单独列出：
   (1) 本模型成立的全部前提；(2) 每个前提被打破时模型如何修正；(3) 通往一般情形的建模路径。
结构要素若我没给定，先问我，不要默认补成对称/规则情形。

任务：【在此粘贴】
```

## D —— 审校既有推导（审校模式）

```
调用 theoretical-derivation skill 的审校模式，审以下推导。只查链条实不实，不评价篇幅：
- P1：有无未经声明就默认补全的结构假设？
- P2：通解项数是否等于定解条件数？有无因预判结果省略的项？
- P3：每个计数/取值是否交代了依据？
- P4：是否审视了有效域（前提 / 失效条件 / 推广路径）？
- 数值：选一个外部锚点（闭式解/特例退化/第二推导），若有 Python 环境请实跑对照。
输出：问题清单（位置 / 违反的规则 / 修正），不改无问题的部分；最后给出四问闸门结论。

推导：【在此粘贴或给出文件路径】
```

## F —— 外部 AI 委派（C 环境）

**Claude 生成前先向用户确认三项**：外部 AI 模型名、产物前缀（默认 `C-<模型名>`）、外部 AI 的工作目录。然后用 R0 通过版与 R3.5 冻结表填充下方占位，整份交用户粘贴给外部 AI。启动指令本身存为 `work/<任务>/C/[C-<模型名>]委派指令_v1.md`。

```markdown
# 【任务名】—— 独立理论推导（外部第二意见）

你作为独立推导者，从零推导本问题，给出你自己的推导链与结果，并主动指出我方框架可能的盲区。

## 0. 文件写入约束（最优先）
- 你的工作目录 = 【外部AI工作目录】。一切文件创建/修改/删除只能发生在此目录内。
- 严禁触碰此目录之外的任何文件；我提供的材料仅供只读参考。

## 1. 独立性约束
- 不要参考、猜测或复制任何已有结论，从问题本身独立推导。
- 若我附了前期结果作基线，独立推导阶段不得引用，只在最后对照。

## 2. 问题与背景
【R0 §3 问题陈述、输入/输出、已钉死的结构要素】
约定（严格遵守，不确定处显式标注，不擅自改选）：【R0 §2 约定】
数值参数（与主线一致）：【R3.5 冻结表】

## 3. 请你完成
1. 用你的话重述问题、假设（≥5 条；缺失的结构不要补成最规则情形，列为待确认）、约束、验证判据。
2. 分阶段完整推导：不因预判省略中间项；每个计数/取值说明来源。
3. 核心公式 + 用上述参数代入的关键数值。
4. 自验证：符号/量纲/边界/极端四类自查；有条件请用 sympy/numpy 实跑并附代码与输出。
5. ★ 盲区与边界：我方问题框架可能漏了什么？模型何时失效？有无更一般的路径？
6. （若附了基线）与基线对照；分歧先判口径差，再判推导错误。
引用须可溯源，禁止编造文献与卷期页。

## 4. 开始前确认（先回复，等我确认再动笔）
1. 你使用的是什么模型？产物用什么前缀标记？（由我指定）
2. 复述你的工作目录，并确认只在该目录内写文件。
3. 背景材料是否齐备？缺什么请告诉我。

产物：一份 markdown，文件名 `[<前缀>]【任务名】_独立推导_v1.md`，写在你的工作目录下。
```

**生成后提示用户**：复制代码块正文并附上所需材料，粘贴到外部 AI 首条消息；外部产物由用户检查后手动拷入 `work/<任务>/C/`，再交主线核对（`cross-validation.md` §6）。
